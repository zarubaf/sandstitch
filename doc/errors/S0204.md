# S0204: field access through union

Fields cannot be selected through a union type because its members overlap, so a member has no bit range of its own. `field` panics with the rendered diagnostic.

## Example

```systemverilog
package sel_pkg;
  typedef struct packed { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
  typedef union packed { logic [11:0] raw; hdr_t hdr; } hdr_u;
endpackage
module sel import sel_pkg::*; (input hdr_u u_i); endmodule
```

```rust
sel.get_port("u_i").field("hdr.dst_id");
```

```text
error[S0204]: cannot select field `hdr` through union `sel_pkg::hdr_u`
  --> tests/diagnostics/typed.rs:88:29
   |
88 |         sel.get_port("u_i").field("hdr.dst_id");
   |                             ^^^^^ field selected here
   |
  ::: tests/diagnostics/fixtures/typed.sv:24:15
   |
24 |   input hdr_u u_i
   |               --- `u_i` declared here as `sel_pkg::hdr_u`
   |
   = note: selecting from `sel.u_i`
   = note: union members overlap, so a field has no bit range of its own
   = help: connect the whole union, or use `connect_bits` to reinterpret bits
```

## Fix

Connect the whole union value to an end of an equivalent type, or use `connect_bits` (or a plain `slice`) if a width-only reinterpretation is intended.
