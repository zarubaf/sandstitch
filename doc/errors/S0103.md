# S0103: unsupported port form

The port has unpacked dimensions, a type that is not integral (`real`, `shortreal`, `string`, `event`), an enum with a value that is not a constant integer or that has X or Z bits, is a `ref` port, or connects several signals, which topstitch cannot represent; the port is rejected rather than dropped. Each such port of the module is reported, at its declaration.

## Example

```systemverilog
module m (input logic [7:0] mem [0:3]); endmodule
```

With `cfg` listing that source:

```rust
ModDef::try_from_verilog_with_config("m", &cfg)?;
```

## Fix

Declare the port with packed dimensions (`input logic [3:0][7:0] mem`) or split it into separate ports; use an integral type for the others. To import the module without such ports, set `skip_unsupported: true` in the `ParserConfig`.
