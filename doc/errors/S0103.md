# S0103: unsupported port form

The port has unpacked dimensions or a type that is not integral (`real`, `shortreal`, `string`, `event`), which topstitch cannot represent; the port is rejected rather than dropped. Each such port of the module is reported, at its declaration.

## Example

```rust
ModDef::try_from_verilog_with_config("m", &cfg)?;   // module m has: input logic [7:0] mem [0:3]
```

## Fix

Declare the port with packed dimensions (`input logic [3:0][7:0] mem`) or split it into separate ports; use an integral type for the others. To import the module without such ports, set `skip_unsupported: true` in the `ParserConfig`.
