# S0203: index out of range

`index(i)` selects an element of the outermost packed dimension by its SystemVerilog index, and `i` lies outside the declared range, or the type has no packed dimension, or the slice has no type. `index` panics with the rendered diagnostic.

## Example

```systemverilog
package sel_pkg;
  typedef struct packed { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
endpackage
module sel import sel_pkg::*; (input hdr_t [7:0] hdrs_i); endmodule
```

With `cfg` listing that source:

```rust
let sel = ModDef::from_verilog_with_config("sel", &cfg);
sel.get_port("hdrs_i").index(8);
```

```text
error[S0203]: index 8 is out of range for `sel_pkg::hdr_t [7:0]`
  --> tests/diagnostics/typed.rs:80:32
   |
80 |         sel.get_port("hdrs_i").index(8);
   |                                ^^^^^ index selected here
   |
  ::: tests/diagnostics/fixtures/typed.sv:23:21
   |
23 |   input hdr_t [7:0] hdrs_i,
   |                     ------ `hdrs_i` declared here as `sel_pkg::hdr_t [7:0]`
   |
   = note: selecting from `sel.hdrs_i`
   = note: the outermost dimension is `[7:0]`
```

## Fix

Use an index within the declared range (here 0 to 7). For bits of a vector without dimensions, use `bit` or `slice`.
