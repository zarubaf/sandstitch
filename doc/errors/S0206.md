# S0206: unpacked aggregate connected as bits

An instance port of an unpacked struct or union type (`struct` or `union` without `packed`) would be emitted as a flat vector, a bit slice or a literal. An unpacked aggregate has no bit layout, so SystemVerilog does not assign those to it, and the emitted RTL would not elaborate. Emitted RTL can connect it only whole, through a net declared with its type: the port must be connected whole to a port of the same type, named with its package. Unpacked types are nominal: a type of another name with the same layout does not connect (Slang: no implicit conversion). `ModDef::check` reports the violation at the port's declaration; `emit` panics with it.

The same applies to the ports of every definition emitted from the model below the emitted module (`Usage::EmitDefinitionAndDescend`): emission may declare such a port flat (tied off, or driven from bits), while its instance in the parent connects to it as an unpacked aggregate. A port of the emitted module itself is checked only when it is connected to an instance port; otherwise a flat declaration is legal. A stubbed definition (`Usage::EmitStubAndStop`) declares its ports with their types and is fine.

A typedef alias of an unpacked type (`typedef nm_pkg::hdr_t hdr_alias_t;`) is reported under the alias's name, so connecting it to the type it names is reported too, although SystemVerilog accepts it.

## Example

`sel.sv`:

```systemverilog
package sel_pkg;
  typedef struct { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
endpackage
module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
```

With `cfg` listing that source:

```rust
let sel = ModDef::from_verilog_with_config("sel", &cfg);
let top = ModDef::new("top");
top.instantiate(&sel, Some("s"), None).get_port("hdr_i").tieoff(0);
let diagnostics = top.check();
```

```text
error[S0206]: unpacked `sel_pkg::hdr_t` port `top.s.hdr_i` cannot be connected as bits
 --> sel.sv:4:44
  |
4 | module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
  |                                            ^^^^^ `top.s.hdr_i` is `sel_pkg::hdr_t`
  |
  = note: it is tied off
  = note: an unpacked struct or union has no bit layout: emitted RTL can only connect it whole, through a net of its type
  = help: connect the whole port to a port of the same type, named with its package, or declare the type `packed`
```

## Fix

Connect the whole port to a port of the same type, named with its package, or declare the type `struct packed` (or `union packed`) so that it has a bit layout.
