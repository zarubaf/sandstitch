# S0206: unpacked aggregate connected as bits

An instance port of an unpacked struct or union type (`struct` or `union` without `packed`) would be emitted as a flat vector, a bit slice or a literal. An unpacked aggregate has no bit layout, so SystemVerilog does not assign those to it, and the emitted RTL would not elaborate. Emitted RTL can connect it only whole, through a net declared with its type: the port must be connected whole to a port of an equivalent type, and both types must be named with their package. `ModDef::check` reports the violation at the port's declaration; `emit` panics with it.

The same applies to a port of the emitted module that is connected to such an instance port. A port of the emitted module that is not, for example one tied off inside a re-emitted definition, is declared flat and is fine.

## Example

`sel.sv`:

```systemverilog
package sel_pkg;
  typedef struct { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
endpackage
module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
```

With `cfg` listing that source:

```rust
let sel = ModDef::from_verilog_with_config("sel", &cfg);
let top = ModDef::new("top");
top.instantiate(&sel, Some("s"), None).get_port("hdr_i").tieoff(0);
let diagnostics = top.check();
```

```text
error[S0206]: unpacked `sel_pkg::hdr_t` port `top.s.hdr_i` cannot be connected as bits
 --> sel.sv:4:44
  |
4 | module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
  |                                            ^^^^^ `top.s.hdr_i` is `sel_pkg::hdr_t`
  |
  = note: it is tied off
  = note: an unpacked struct or union has no bit layout: emitted RTL can only connect it whole, through a net of its type
  = help: connect the whole port to a port of an equivalent type named with its package, or declare the type `packed`
```

## Fix

Connect the whole port to a port of an equivalent type named with its package, or declare the type `struct packed` (or `union packed`) so that it has a bit layout.
