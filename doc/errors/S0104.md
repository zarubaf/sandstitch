# S0104: interface port unsupported

The port is a SystemVerilog interface port, which is not supported; the port is rejected rather than dropped. Each interface port of the module is reported, at its declaration.

## Example

```systemverilog
interface bus_if; logic valid; modport mst (output valid); endinterface
module m (bus_if.mst bus); endmodule
```

With `cfg` listing that source:

```rust
ModDef::try_from_verilog_with_config("m", &cfg)?;
```

## Fix

Replace the interface port with its constituent signals or a packed struct port.
