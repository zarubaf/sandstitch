# S0104: interface port unsupported

The port is a SystemVerilog interface port, which is not supported; the port is rejected rather than dropped. Each interface port of the module is reported, at its declaration. The boundary is deliberate; see [SystemVerilog interface ports](../design/typed-specialization.md#systemverilog-interface-ports).

## Example

```systemverilog
interface bus_if; logic valid; modport mst (output valid); endinterface
module m (bus_if.mst bus); endmodule
```

With `cfg` listing that source:

```rust
ModDef::try_from_verilog_with_config("m", &cfg)?;
```

## Fix

Instantiate the module the interface wraps, if there is one: IP such as `axi_xbar_intf` wraps a struct-port module (`axi_xbar`) that imports. Otherwise replace the interface port with its constituent signals or a packed struct port.
