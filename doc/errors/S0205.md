# S0205: field access on an unpacked struct

Fields cannot be selected from an unpacked struct (`struct` without `packed`): it has no bit layout of its own, so a field has no bit range. `field` panics with the rendered diagnostic. Connecting the whole struct to an end of an equivalent unpacked struct is fine.

## Example

`sel.sv`:

```systemverilog
package sel_pkg;
  typedef struct { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
endpackage
module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
```

With `cfg` listing that source:

```rust
let sel = ModDef::from_verilog_with_config("sel", &cfg);
sel.get_port("hdr_i").field("len");
```

```text
error[S0205]: cannot select field `len` of unpacked struct `sel_pkg::hdr_t`
 --> src/main.rs:2:23
  |
2 | sel.get_port("hdr_i").field("len");
  |                       ^^^^^ field selected here
  |
 ::: sel.sv:4:44
  |
4 | module sel import sel_pkg::*; (input hdr_t hdr_i); endmodule
  |                                            ----- `hdr_i` declared here as `sel_pkg::hdr_t`
  |
  = note: selecting from `sel.hdr_i`
  = note: an unpacked struct has no bit layout, so a field has no bit range of its own
  = help: connect the whole struct, or declare it `struct packed`
```

## Fix

Connect the whole struct, or declare the type `struct packed` so that its fields have bit ranges.
