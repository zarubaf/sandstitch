# S0102: Slang elaboration error

Slang rejected the source while elaborating one specialization. The diagnostic carries Slang's own messages as notes and the SystemVerilog span Slang reported as the primary label; all Slang errors for that specialization are reported together.

## Example

```rust
let router = ModDef::try_from_verilog_with_config("floo_nw_router", &cfg)?;   // cfg sources reference an undefined package
```

## Fix

Fix the SystemVerilog error shown in the snippet (missing source, undefined identifier, bad parameter value) and re-run.
