# S0406: inout conflict

A component (bits joined by connections inside one definition) is carried by one net, and a definition port is that net. Two definition inouts on one component, or a definition inout with a definition input or output, would make two ports one net, which SystemVerilog cannot express. `ModDef::check` reports the component once, about its first end in declaration order; `emit` panics with it.

## Example

```rust
let top = ModDef::new("top");
let p = top.add_port("p", IO::InOut(8));
let q = top.add_port("q", IO::InOut(8));
p.connect(&q);
let diagnostics = top.check();
```

```text
error[S0406]: inout conflict on `top.p`: several definition inouts (`top.p`, `top.q`)
 --> src/main.rs:4:3
  |
4 | p.connect(&q);
  |   ^^^^^^^ connected here
```

## Fix

Keep at most one definition port on an inout net, for example by exposing the net through a single inout port.
