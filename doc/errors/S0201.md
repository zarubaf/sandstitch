# S0201: incompatible types

Typed ends must have structurally equivalent types; equal width is not enough. The diagnostic names the first differing field, with the Rust call site as the primary label.

## Example

```rust
a_req.connect(&b_req);   // req_t vs an equal-width struct with a different field layout
```

## Fix

Connect ports of equivalent types, or use `connect_bits(a, b)` to record an intentional width-only reinterpretation.
