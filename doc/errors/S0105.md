# S0105: unsupported override

An override value cannot be emitted or does not fit its parameter.

Explicit overrides (`try_parameterize`, `try_from_verilog_parameterized`):

- `ParameterValue::Type` and `ParameterValue::Expr` accept only `ident` or `pkg::ident`, naming a type or a constant.
- A type for a value parameter, or a value for a type parameter.
- An integer that is negative or does not fit its parameter's type.
- A string with characters other than printable ASCII, or with quotes or backslashes.

A bare `ident` refers to the generated elaboration top's compilation unit, so it resolves only with `--single-unit` in the configuration's extra arguments (otherwise Slang fails, S0102); prefer `pkg::ident`.

Slang `-G` values (`ParserConfig::parameters`). These are the canonical rules:

- A `-G` value of a parameter the module does not declare is ignored, as by Slang, so one configuration can serve several modules.
- A `-G` value of a parameter the module declares is kept: a plain import emits it as an override of its instances (its ports were resolved with it), and every specialization applies it as a base override. An explicit override of the same parameter replaces it.
- Each kept value must be a decimal integer, a string literal or a name, and set a value parameter (Slang applies `-G` only to value parameters). Anything else (`8'hff`, `1+1`, a type parameter) is S0105.
- A kept name set twice is S0105, since Slang would apply the first. A name the module does not declare, or one an explicit override replaces, may be set twice.
- The code is reported at import for a plain import, and at specialization for `try_parameterize` and `try_from_verilog_parameterized`.

## Example

```systemverilog
module router #(parameter type flit_t = logic) (input flit_t flit_i); endmodule
```

With `cfg` listing that source:

```rust
let router = ModDef::try_from_verilog_with_config("router", &cfg)?;
router.try_parameterize(&[("flit_t", ParameterValue::Type("struct packed { logic a; }".into()))])?;
```

## Fix

Define a named type in a package and override with `ParameterValue::Type("cfg_pkg::flit_t".into())`.
