# S0208: interface member repeated in one direction

An interface defined with `def_intf_members` may have a name at most once per port direction, so that `connect` can tell which member pairs with which. Two members of one name and direction are reported at the definition.

## Example

`node.sv`:

```systemverilog
package node_pkg;
  typedef struct packed { logic valid; logic [7:0] data; } req_t;
  typedef struct packed { logic ready; logic [3:0] code; } rsp_t;
endpackage
module node import node_pkg::*; (
  input req_t [1:0] req_i, output req_t [1:0] req_o,
  input rsp_t [1:0] rsp_i, output rsp_t [1:0] rsp_o
);
endmodule
```

With `cfg` listing that source:

```rust
let node = ModDef::from_verilog_with_config("node", &cfg);
node.def_intf_members("link", [("req", node.get_port("req_o").index(0)), ("req", node.get_port("req_o").index(1))]);
```

```text
error[S0208]: member `req` is an output twice in interface `node.link`
 --> src/main.rs:2:6
  |
2 | node.def_intf_members("link", [("req", node.get_port("req_o").index(0)), ("req", node.get_port("req_o").index(1))]);
  |      ^^^^^^^^^^^^^^^^ interface defined here
  |
  = note: `node.req_o[0]` and `node.req_o[1]` are both outputs
  = help: a name may appear once per direction; give one of them another name
```

## Fix

Give the members distinct names (`req0`, `req1`), or define one interface per element.
