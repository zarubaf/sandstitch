# S0101: unknown parameter

A parameter or type override names something the module does not declare.

## Example

```systemverilog
package cfg_pkg;
  typedef struct packed { logic [7:0] data; logic last; } flit_t;
endpackage
module router #(parameter type flit_t = logic) (input flit_t flit_i); endmodule
```

With `cfg` listing that source:

```rust
let router = ModDef::try_from_verilog_with_config("router", &cfg)?;
router.try_parameterize(&[("flit_tt", ParameterValue::Type("cfg_pkg::flit_t".into()))])?;   // the module declares `flit_t`
```

## Fix

Use a parameter name declared by the module.
