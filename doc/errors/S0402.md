# S0402: unconnected bits

Every bit of every end of a definition (each port of each instance, and each port of the definition) must be connected, tied off or marked unused. `ModDef::check` reports each maximal range of bits that is none of these, naming the exact range (omitted when it is the whole port), with the creation of the definition (`ModDef::new`) as the label; `emit` panics with it.

## Example

`snk.sv`:

```systemverilog
module snk(input logic [7:0] i); endmodule
```

With `cfg` listing that source:

```rust
let snk = ModDef::from_verilog_with_config("snk", &cfg);
let top = ModDef::new("top");
let u = top.instantiate(&snk, Some("u"), None);
u.get_port("i").slice(7, 4).tieoff(0);
let diagnostics = top.check();
```

```text
error[S0402]: `top.u.i[3:0]` is not connected
 --> src/main.rs:2:11
  |
2 | let top = ModDef::new("top");
  |           ^^^^^^ defined here
  |
  = help: connect it, tie it off, or mark it unused
```

## Fix

Connect the bits, tie them off (`tieoff`) or mark them unused (`unused`); `unused_or_tieoff` picks the one the port's direction allows.
