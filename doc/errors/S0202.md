# S0202: no such field

`field` names a member that the selected type does not have: the struct has no such field, the type is a packed array (select an element with `index` first) or not a struct at all, or the slice has no type (a plain bit slice or a port added without a type). This is a programming error at the call site, so `field` panics with the rendered diagnostic.

## Example

```systemverilog
package sel_pkg;
  typedef struct packed { logic [3:0] dst_id; logic [7:0] len; } hdr_t;
endpackage
module sel import sel_pkg::*; (input hdr_t [7:0] hdrs_i); endmodule
```

With `cfg` listing that source:

```rust
let sel = ModDef::from_verilog_with_config("sel", &cfg);
sel.get_port("hdrs_i").index(3).field("dst_idd");
```

```text
error[S0202]: no field `dst_idd` in `sel_pkg::hdr_t`
  --> tests/diagnostics/typed.rs:72:41
   |
72 |         sel.get_port("hdrs_i").index(3).field("dst_idd");
   |                                         ^^^^^ field selected here
   |
  ::: tests/diagnostics/fixtures/typed.sv:23:21
   |
23 |   input hdr_t [7:0] hdrs_i,
   |                     ------ `hdrs_i` declared here as `sel_pkg::hdr_t [7:0]`
   |
   = note: selecting from `sel.hdrs_i[3]`
   = note: available fields: `dst_id`, `len`
```

## Fix

Use a field path that exists in the struct type (`"dst_id"`), and select array elements with `index` before their fields.
